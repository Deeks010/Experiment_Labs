# cctv-agent — research and design for the factory CCTV supervisor agent

**This folder is the research archive (rounds 1-6). The live project memory is ../CLAUDE.md.**

- `CLAUDE.md` — project memory and instructions for the agent working here.
- `docs/` — results log (HANDOFF.md), agent design, conversation log, sources, figures.
- `round1_2/ … round6/` — all experiments: simulator, data formats, prompts, model answers, scores.

Setup: `pip install -r requirements.txt`. Run a round from inside its folder, e.g. `cd round3 && python3 stress.py`.
